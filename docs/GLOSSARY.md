# Glossary

Domain vocabulary. One row per term, each pointing at the file or ADR that
defines it. A term belongs here as soon as it appears in a type name, a table
name, or a conversation where two people could mean different things by it.

Rules:

- The **canonical home** column is the single place the term is defined. This
  file points there; it does not duplicate the definition.
- If a term has a different meaning in the UI than in the database, that is
  two rows, not one sentence with a "but".
- Keep terms alphabetical. The ordering is a grep anchor.
- Deprecated terms stay listed with their replacement, because old code and
  old sessions still use them.
