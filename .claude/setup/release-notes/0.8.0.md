### Features

- Every reply your sessions give now ends with the same three sections: `Good to know`, `Act later` and `Act next`. `Act next` is always present, so you never have to work out what the session is waiting on. The other two appear only when they have something in them, so an empty section never pads the reply.
- `Act later` names where deferred work should be done, so a change a session cannot make right now reaches you with its destination attached rather than as a vague note.
- Questions a session asks you are themselves the `Act next` items. The shape of a reply stays the same whether the session is asking you something or telling you something.
- Grill question numbers now run continuously. A round following one that ended at Q6 opens at Q7, so answering by number stays unambiguous after you scroll back. A later round of questions in a different phase takes a new letter, and the session says in one sentence why the letter moved.

### Improvements

- The three sections are a compression device, not an addition. The prose above them carries only what they cannot, so replies get shorter rather than longer.
- Several skills working on one reply now produce one set of sections instead of one per skill.
- `/chat` gains the most structure, because nothing else shaped its replies before. A change that came out of a chat now arrives in `Act later` naming the kind of session that can make it.

### Notes

- Nothing you own changes. The behaviour lives in the harness-managed skill files and arrives with `/harness-upgrade` like any other skill update, so there is no migration step and nothing to edit by hand.
