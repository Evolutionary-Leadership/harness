### Improvements
- `/release` step 7b, which writes the release note published on a template repo, now says what to do when the draft comes back unwritten. The drafter marks the gap rather than claiming the release changes nothing downstream, and the step names the two causes worth checking and how to tell them apart from the report. Step 7b skips itself in any project that does not publish a template repo of its own, so if yours does not, nothing here changes what your project does and this upgrade is optional.
